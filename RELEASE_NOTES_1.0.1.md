# Access Gateway 1.0.1

Documentation and language clarification release based on user feedback.

## Changes

- Clarified the English description of **Act as access gateway**.
- Improved the Dutch description and made the permission behaviour more precise.
- Explicitly documented that the gateway setting is edited via **ACP > Forums > Manage forums > green gear icon**.
- Documented that normal group forum permissions remain under **ACP > Permissions > Group forum permissions**.
- Clarified the default (`No`) behaviour: hiding/denying a category does not by itself block access to child forums; their own permissions continue to apply.

## Compatibility

- phpBB 3.3.16+
- phpBB 3.x
- PHP 7.1.3+

There are no database, schema, or permission-logic changes in this release.
